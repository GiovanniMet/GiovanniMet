# Giovanni Metitieri

Senior IT Infrastructure & Automation Engineer, based in Rome, Italy.

I have spent about 11 years running Linux and virtualization platforms at scale, first in hosting and now in a large regulated online-gaming group. I like on-premise and hybrid infrastructure that is well built, and I automate everything I can.

## What I work with

- **Virtualization and Linux:** VMware private clouds, KVM, Red Hat family and Debian
- **Automation and IaC:** Ansible/AWX, Terraform, Atlantis, GitLab CI, PowerShell, Bash
- **Networking and DNS:** PowerDNS, dnsdist, Unbound, HAProxy, VLAN design
- **Edge and security:** Cloudflare (WAF, bot mitigation, Workers, mTLS), PKI, FreeIPA
- **Observability:** Icinga2, Prometheus, Grafana, Loki, ELK
- **Mail:** Postfix at scale, SPF/DKIM/DMARC

## Public projects

- [kiro-community-repo](https://github.com/GiovanniMet/kiro-community-repo): an unofficial signed APT repository for Kiro IDE, rebuilt every 6 hours with GitHub Actions and GPG.
- [kiro-community-worker](https://github.com/GiovanniMet/kiro-community-worker): the Cloudflare Worker in front of that repository.

## At home

A TrueNAS SCALE NAS, Home Assistant, and a small VPN setup, with encrypted disks and 3-2-1 backups.
